## ❓ O que é?

Um app de chamada estilo Discord, mas **sem servidor na nuvem**: um PC da turma
hospeda (quem hospeda vira o **Dono** da sala) e todo mundo conecta direto nele.

Tem **voz com anti-eco, compartilhamento de tela com som do jogo/PC, chat com
envio de arquivos** e atividades em conjunto sincronizadas: **🎬 Cinema,
🎵 Música, 🎞️ Sessão Livre e 🎮 Jogos** (jogo da velha, dominó, forca…).

Tudo é salvo **criptografado** no PC do host — nenhuma nuvem, nenhuma conta,
nenhum cadastro pra usar.

## 🔌 Os 3 jeitos de conectar

| Método | Pra quem é | Instala algo? | Precisa de login? |
|---|---|---|---|
| 🟢 **Radmin VPN** | Turma de PC — o **mais rápido e estável** | O app gratuito [Radmin VPN](https://www.radmin-vpn.com/), em todos os PCs | ❌ Não |
| 🟠 **Link Temporário** | Convidado na hora, **sem instalar NADA** | Nada — abre até no navegador | ❌ Não |
| 🏅 **Link Permanente** | Turma fixa — **o endereço nunca muda** | Nada pros convidados | ❌ Pros convidados, não. O host configura 1 vez com conta **gratuita** da Cloudflare |

- **🟢 Radmin VPN (recomendado):** todos entram na mesma rede virtual (grátis)
  → conexão direta, com a latência e estabilidade de uma LAN. O host manda o
  IP `26.x.x.x` ou o **código de convite** (`TC-XXXXXX`).
- **🟠 Link Temporário:** o host gera um link (Cloudflare) e manda pra galera —
  quem recebe abre no **navegador** ou no app. Perfeito pra uma call pontual;
  quando o host encerra o servidor, o link vai junto.
- **🏅 Link Permanente:** o host configura uma vez e fica com o **mesmo link pra
  sempre**. Faltou luz no PC do host? Quando religar, o link volta sozinho com
  o mesmo endereço — ninguém precisa receber link novo de novo.

## ⚠️ A "tela azul" do Windows ao abrir o exe (aparece 1 vez — é normal)

Na primeira execução o Windows pode mostrar o aviso do
**Microsoft Defender SmartScreen**:

> *“O Windows protegeu o computador — um aplicativo desconhecido foi impedido de iniciar.”*

**Por que isso acontece?** Não é vírus. O Windows mostra esse selo para
qualquer programa novo que não carrega o **certificado de assinatura de código**
reconhecido pela Microsoft — e remover 100% do aviso exige comprar o modelo
**EV** desse certificado, que custa **milhares de reais por ano**. Como o
TureteCall é um projeto **gratuito** e independente, esse selo não é comprado —
então o Windows mostra o aviso por padrão, uma única vez.

**Como passar em 10 segundos (só na primeira vez):**

1. Clique em **“Mais informações”**
2. Clique em **“Executar assim mesmo”**

Pronto — o Windows memoriza e não pergunta de novo.
